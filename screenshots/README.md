## 부가정보 / Auxiliary information

기본: 부스트·토크. 배터리 잔량은 배터리 모양, G-force는 사각 트랙과 점으로 표시됩니다. 전압·연비는 게이지 모드에서도 텍스트입니다. 마력의 *는 추정 출력 표기입니다.

Default: boost/torque. Battery charge uses a battery icon; G-force uses a rectangular track and filled dot. Voltage/economy remain text in gauge mode. Power * indicates estimated engine output.
