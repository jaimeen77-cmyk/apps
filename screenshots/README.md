# 스크린샷 모음 · Screenshots — Cluster Redline 1.3.67

[계기판 레드라인 설명서](../docs/CLUSTER-REDLINE.ko.md) · [Cluster Redline guide](../docs/CLUSTER-REDLINE.md) · [설치 안내](../docs/INSTALL.ko.md) · [Installation](../docs/INSTALL.md)

실제 앱 패키지(1.3.67)의 그리기 코드에 예시 데이터를 넣어 만든 화면입니다. 차에서 찍은 사진이 아니며, 차·휴대폰마다 신호 지원이 다를 수 있습니다. HUD의 검은 배경은 그리는 면이며 실제 밝기가 아닙니다.

Drawn by the actual 1.3.67 package's drawing code with example data; not photographs from a car. Signal support differs between cars and phones. The HUD's black background is the drawing surface, not its brightness.

다른 앱의 화면은 각 앱 설명서에 있습니다: [MGU 모니터](../apps/storage/README.ko.md), [아이드라이브 회로](../apps/idrive_circuit/README.ko.md), [8게임즈](../apps/parked_games/README.ko.md), [GIF 플레이어](../apps/gif_home/README.ko.md), [시트 Easy Access](../apps/seats_easy_access/README.ko.md).
