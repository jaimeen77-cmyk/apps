# Cluster Redline 1.3.16 성능 확인

Linux x64(4코어), Node v22.23.5에서 실제 앱 코드를 호스트에서 돌린 결과입니다. 차량 CPU/GPU, SOME/IP, 소켓 전송, 전체 앱 메모리는 이 측정에 포함하지 않습니다. 같은 기계·같은 키트로 1.2.58 코드와 나란히 측정했습니다.

## 1. HUD·계기판 그리기 (`tools/cluster-redline-benchmark.js`, 조건마다 1,500회 × 3번)

한 회에 HUD와 계기판을 모두 그립니다. 100회 예열, 250회마다 강제 GC(비용 포함). CPU ms/회, 3번 평균:

| 조건 | 1.2.58 | 1.3.16 | 차이 |
|---|---:|---:|---:|
| 화면 유지 | 0.368 | 0.357 | −3 % |
| RPM 매번 변경 | 5.711 | 5.886 | +3 % |
| RPM·길안내 매번 변경 | 6.223 | 6.001 | −4 % |

같은 버전을 다시 돌려도 ±10 % 안팎으로 흔들려, 차이는 측정 오차 범위입니다. 강제 GC 후 JS 힙은 측정 동안 약 8.5 → 9 MB로 계속 늘지 않았고, 종료 RSS는 두 버전 모두 약 95 MB, 렌더 캐시는 HUD 2.8 MB·계기판 5.4 MB로 같습니다.

## 2. 1.3.x에서 추가된 부분 (`tools/cluster-redline-features-benchmark.js`, 1,500프레임, worker 20 fps 기준)

| 항목 | CPU ms/프레임 | 비고 |
|---|---:|---|
| HUD 그리기만 (기준, RPM 매번 변경) | 2.77 | |
| HUD + 깜빡이 (레드라인 HUD 안, `<<< >>>`) | 2.33 | 기준과 오차 범위 안 |
| 깜빡이 오버레이 (순정 HUD) | 0.04 | 그림 전송 2번, 깜빡임은 밝기만 502번 |
| 차량 알림 오버레이, 차 거리 문구(10 m 단위) | 0.27 | 업로드 135번, 약 160 KB/s |
| 차량 알림 오버레이, **50 m 단위 표시 (1.3.16)** | 0.12 | 업로드 30번, 약 36 KB/s (−78 %) |
| 표지 인식 해석 (카메라 표지 4개 + 속도, 매 프레임) | 0.05 | 실제 차 신호보다 자주 넣은 조건 |
| 길안내 이벤트 해석 (이벤트 8개, 매 프레임) | 0.05 | 실제로는 1초에 한 번 |
| 운전자 전환 (50프레임마다, 운전자 3명) | 0.46 | 전환 1번 약 23 ms(파일 쓰기 포함), 파일 11 KB, 키 329개 |

차량 알림은 60 km/h로 카메라에 다가가는 상황(프레임마다 0.83 m)으로 측정했습니다. 알림 그림 전체(약 100 KB)를 거리 문구가 바뀔 때마다 다시 보내므로, 1.3.16부터 남은 거리를 50 m 단위(1 km부터 0.1 km 단위)로 표시해 전송량을 줄였습니다.

## 재실행

```sh
node --expose-gc tools/cluster-redline-benchmark.js <빌드-stage> 1500
node --expose-gc tools/cluster-redline-features-benchmark.js <빌드-stage> 1500
```
